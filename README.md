# keirin-value-app

## Ver.1.13.0

WINTICKETの3連単全オッズを使う期待値計算と、機械学習用SQLiteへの
過去レース一括収集、オッズ非依存AI予測を行うStreamlitアプリです。

## 対応環境

- macOS
- Python 3.12 / 3.13
- Google Chrome

## インストール

Finderでこのフォルダを開き、`install.command`をダブルクリックします。
手動で実行する場合は次のとおりです。

```bash
cd ~/Documents/GitHub/keirin-value-app
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m playwright install chromium
```

## 起動

`run.command`をダブルクリックするか、次を実行します。

```bash
cd ~/Documents/GitHub/keirin-value-app
source .venv/bin/activate
python -m streamlit run main.py
```

## Galaxy Z Fold5 端末内AI

Galaxy Z Fold5（Android 14）では、WINTICKETの開催一覧・個別出走表を
アプリ内で取得し、学習済みオッズ非依存AIをスマホ本体だけで実行できます。
モデルと学習DBは公開GitHubやAPKへ含めません。Macで検証済みの非公開ZIPを
作り、Google DriveまたはUSBなどでGalaxyへ渡してアプリ内へ取り込みます。

```bash
cd ~/Documents/GitHub/keirin-value-app
source .venv/bin/activate
python export_android_ai_bundle.py
```

出力は `exports/keirin_android_ai_bundle.zip` です。変換時にMac版モデルと
端末用モデルの確率を比較し、SQLite整合性、ファイルサイズ、SHA-256を
記録します。一致しない場合はZIPを作成しません。詳しいAPK更新・取込・
操作手順は `android-fold5/README.md` を参照してください。

## 過去レース収集

1. 左メニューから「学習データ収集」を開きます。
2. 「過去レース一括インポート」で開始日・終了日・最大取得数を指定します。
3. 「過去レース収集を開始」を押します。
4. 成功・失敗・要確認の一覧と進捗を確認します。

収集はStreamlitとは別のPython Workerで続行します。3連単オッズの全組番が
揃い、重複・不足・無効値がない場合だけ期待値学習用として保存します。
深夜などWINTICKETでオッズが非表示の場合は、不完全なオッズをすべて破棄し、
出走表・選手・コメント・並び・結果をオッズ非依存AI用として保存します。
昼間に同じ期間を再実行すると、同じレースを重複登録せず、完全オッズが
取得できたレースだけ期待値学習用へ自動更新します。
旧バージョンで登録済みのレースは、新しい拡張特徴が未取得の場合だけ
再収集します。既存の完全オッズと確定結果を保持したまま、選手属性、
レース条件、並び取得方式を補完します。

組番やオッズの推測補正は行いません。同着、複数払戻、失格、中止、
不成立は「要確認」として保存し、自動確定しません。

SQLiteの保存先は `data/keirin_learning.db` です。
旧SQLiteから初回移行する直前に、
`data/backups/keirin_learning_before_history_import_日時.db`
へ自動バックアップします。

## オッズ非依存AI

左メニューの「オッズ非依存AI」は、3連単オッズ、人気順位、市場確率、
払戻金、WINTICKET AI印を学習にも予測にも使用しません。

学習には結果確定済みレースの競走得点、脚質、S/H/B、勝率、
2連対率、3連対率、選手コメント、並びに加え、次の拡張特徴を使用します。

- 選手ID、府県、級班、年齢、期別
- 競輪場の周長、みなし直線、最大カント
- グレード、勝ち上がり区分、開催日目、発走時刻、距離、周回数、天候、気温、風
- 対象日より前の直前5走・10走、同じ競輪場での直近成績
- DOM構造と選手コメントの整合確認を経た並び、並び信頼度

直近成績は対象日より前の確定結果だけから作り、同じ開催日の結果は
その日の別レースへ混ぜません。同着や中止など「要確認」のレースは
学習対象外です。

1. 複数日にわたる過去レースを収集します。
2. 「オッズ非依存AI」ページで最低学習レース数と日付順検証数を指定します。
3. 「オッズ非依存AIを学習」を押します。
4. メイン画面で予測対象レースの出走表と並びを取得します。
5. 「オッズ非依存AI」ページへ戻り、「オッズを使わず予測」を押します。

動作確認は30レースから可能ですが、評価には300〜500レース以上、
本格利用には1,000レース以上を推奨します。学習済みモデルは
`models/keirin_odds_independent_model.joblib` に保存され、再学習時は
`models/backups` へ旧モデルをバックアップします。

現在レースはメイン画面の「レースデータを取得」から読み込みます。
深夜などオッズが非表示でも、出走表・選手コメント・並びを取得して
現在レース用JSONへ保存します。その後「オッズ非依存AI」ページで
「オッズを使わず予測」を実行できます。期待値計算は完全オッズが
取得できた場合だけ利用できます。

予測ページは、対象日・競輪場・R番号・選手・並びを、メイン画面で
最後に保存した1つの現在レースJSONから一括で読み込みます。ページ間の
古いセッション情報とは混在しません。予測対象が違う場合は、メイン画面へ
戻って対象レースを選び、「レースデータを取得」をもう一度押してください。

### 独立AIの客観評価

「オッズ非依存AI」ページで予測すると、その時点の全組番のAI順位と
AI確率をSQLiteへ固定保存します。同一レース・同一モデルで再実行しても
初回予測を上書きしません。学習データ収集で結果が登録されると、
的中組番のAI順位、Top1・Top5・Top10・Top20・Top30的中、払戻を
自動照合します。

自己評価履歴のR欄をクリックすると、予測時に固定保存した選手別の
1着・2着・3着・3着内確率と、3連単全組番のAI順位・AI確率を
ポップアップで確認できます。結果確定済みの場合は、実際の的中組番も
表示します。

正式評価に含むのは、対象日がモデル学習終了日より後、発走前に予測、
予測時点で結果未登録、同一レースの初回正式予測という条件をすべて
満たしたレースだけです。条件外の予測は参考記録として保存します。
発走時刻を取得できたレースは時刻まで比較し、発走時刻がない旧データだけ
開催日単位で判定します。
既存モデルには学習期間または当日除外の締切日が記録されていないため、
正式評価を始める前に一度モデルを再学習してください。

### 当日レースの学習除外

オッズ非依存AIは、日本時間の前日を学習締切日にして、当日以降の
確定レースを自動的に学習対象から除外します。当日の途中で結果収集後に
再学習しても、その日の後半レースへ当日結果が混ざりません。
画面には学習締切日と自動除外件数を表示し、モデルと予測履歴にも
その情報を保存します。
